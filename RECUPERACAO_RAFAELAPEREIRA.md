1. O que é uma Issue e para que serve no desenvolvimento de software?
  Issue significa "problema" em inglês e é um recurso usado no desenvolvimento para documentar e organizar as tarefas. É um registro para melhorar o trabalho em equipe. É usada principalmente para reportar bugs, sugerir melhorias e gerenciar tarefas

2. O que é um Pull Request e por que ele é importante?
  O Pull Request é uma requisição formal para que alguma alteração feita seja incorporada no projeto. É importante para organizar as alterações de forma que elas sejam avaliadas antes de colocadas no arquivo original

3. O que é separação de camadas no código?
  É a divisão do código em partes com responsabilidades bem definidas, cada camada faz apenas uma coisa. Um exemplo disso é o app.py, que é onde o usuário irá fazer requisições e receber respostas e o repositorio.py, que é onde fica o acesso ao banco de dados, ou seja, onde fica o SQL
